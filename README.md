# Hallie Calhoun Portfolio

Personal site for Hallie Calhoun, a software engineer in San Diego.

**Live site:** [https://halliecalhoun.github.io/Portfolio-Website/](https://halliecalhoun.github.io/Portfolio-Website/)

## Deploy

GitHub Pages publishes this repository from the `master` branch, folder `/`. There is no build step. `index.html`, `css/site.css`, and `js/site.js` are the site. Pushing to `master` updates the live page.

`home2.html` redirects to the homepage. It used to be an old template page.
